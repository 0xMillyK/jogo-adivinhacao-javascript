# 🎮 Jogo de Adivinhação em JavaScript

Um jogo de adivinhação desenvolvido com **HTML, CSS e JavaScript**, no qual o jogador precisa descobrir um número secreto entre 1 e 1000.

## 🎯 Sobre o projeto

O projeto foi desenvolvido como prática dos fundamentos de JavaScript, trabalhando conceitos como variáveis, condicionais, funções, geração de números aleatórios e interação com o usuário.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

## ✨ Funcionalidades

* Geração aleatória de um número secreto entre 1 e 1000
* Entrada de palpites pelo jogador
* Contagem de tentativas
* Indicação se o palpite é maior ou menor que o número secreto
* Mensagem de vitória ao acertar o número
* Interface estilizada com HTML e CSS

## ▶️ Como executar

1. Clone este repositório:

   ```bash
   git clone https://github.com/0xMillyK/jogo-adivinhacao-javascript.git
   ```

2. Abra a pasta do projeto.

3. Abra o arquivo `index.html` no navegador.

4. Comece a jogar! 🎮
